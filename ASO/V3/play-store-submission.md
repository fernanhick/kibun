### Under-the-hood changes (for the team — not for the listing)

These ship in V3 but are not user-visible at the listing level. Documented so QA knows what to test.

**Cross-device data sync (the headline fix)**
- On sign-in, `useAuth.ts` now pulls `habits`, `habit_logs`, `custom_moods`, and `life_events` from Supabase — previously only `mood_entries` was pulled, so fresh logins on a new device showed empty lists for everything except moods.
- On sign-out, all four data stores are cleared (was: only mood entries). Prevents the previous user's data leaking into the next session on shared devices.

**Anonymous → registered data preservation**
- New `handleRegisteredUserSync` orchestrator detects anon→registered upgrade (prev `authStatus === 'anonymous'` with same `userId`) and uploads all four local stores to Supabase *before* the merge step runs. Without this, the merge would overwrite local anon data with an empty remote and the upgrade would silently lose everything the user logged before creating an account.
- New `USER_UPDATED` handler routes through the same orchestrator. This is the event Supabase fires for `auth.updateUser({ email, password })`, which is the canonical anon→registered upgrade path.
- Defensive: account-switch path (different `userId`, no `SIGNED_OUT` fired in between) explicitly clears local stores before sync to prevent attributing the previous account's data to the new user.

**Habits UI refresh**
- `app/manage-habits.tsx`: replaced full-width swipe-to-delete rows with a 2-column card grid; each card has a small inline trash icon. Swipe gesture and its supporting styles removed.
- `app/(tabs)/index.tsx`: replaced full-width habit rows with a compact 2-column grid; boolean habits render inline with a checkbox, scale habits render with a 5-dot row stacked below the name. Habits are also pre-sorted by tracking type so same-height cards land on the same grid row (fixes the staircase whitespace issue).

**Files touched:** `src/hooks/useAuth.ts`, `app/manage-habits.tsx`, `app/(tabs)/index.tsx`, `src/i18n/locales/en/screens.json`, `src/i18n/locales/es/screens.json`.

**Regression surface to test on internal track:**
1. Fresh install → use app anonymously → create account → confirm anon mood/habit/life-event/custom-mood rows appear in Supabase under the new user_id.
2. Sign in on a brand-new device with an existing account → confirm habits, life events, and custom moods restore (previously only moods did).
3. Sign out from account A → sign in to account B → confirm no data leakage from A.
4. Anonymous-only usage path → app works fully offline-from-account, no unintended Supabase writes.
